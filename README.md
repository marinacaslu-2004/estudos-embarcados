# Estudos de Firmware e Sistemas Embarcados

Repositório dedicado ao meu aprendizado progressivo em desenvolvimento de firmware, sistemas embarcados e programação de baixo nível (C/C++).

## 🚀 Sobre o Projeto
Este repositório documenta minha jornada de estudos, desde a manipulação básica de memória até o desenvolvimento profissional de drivers para microcontroladores. 

Foco atual: **Módulo 1 — Fundamentos de C para Sistemas Embarcados.**

## 📂 Estrutura do Repositório
* `src/`: Códigos-fonte em C.
* `include/`: Arquivos de cabeçalho (`.h`).
* `docs/`: Documentação e anotações de estudo.

## 🛠️ Tecnologias e Conceitos
- Linguagem: C
- Conceitos: Aritmética de ponteiros, alocação de memória, manipulação de arrays e buffers, padrão de codificação profissional.
- Ferramentas: Git/GitHub, GCC, PowerShell.

## 📝 Aulas Concluídas
- **Aula 1:** Alocação Estrita de Memória e uso de `stdint.h`.
- **Aula 2:** Mapa da Memória e Ponteiros (`&`, `*`).
- **Aula 3:** Aritmética de Ponteiros e Arrays em firmware.
